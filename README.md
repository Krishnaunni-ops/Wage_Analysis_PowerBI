# Power BI Dashboard: Wage Analysis in Canada

## Overview
This Power BI project provides an interactive dashboard analyzing wage trends in Canada. The dashboard includes visualizations on average and median wages by industry, gender, and province, allowing for deeper insights into wage distribution and growth.

## Features
- **Time-Series Analysis**: Trends in average hourly wages across industries.
- **Geospatial Insights**: Wage distribution by province.
- **Industry Comparison**: Wage differences across various industries.
- **Demographic Breakdown**: Analysis by gender.
- **KPI Cards**: Key wage indicators for quick insights.

## Data Source
- The dataset used is **sample data** for demonstration purposes.
- It contains information on:
  - **Average and Median Hourly Wages**
  - **Average and Median Weekly Wages**
  - **Industry classification (NAICS)**
  - **Geographic location (Provinces in Canada)**
  - **Demographic details (Gender, Age group)**
  - **Monthly wage records**

## Power BI Visuals Included
1. **Bar Chart**: Wage distribution by industry and gender.
2. **Line Chart**: Wage trends over time by industry.
3. **Map Visualization**: Wage distribution across Canadian provinces.
4. **KPI Cards**: Displaying total average hourly wage and total median weekly wage.
5. **Slicers**: Interactive filters for Month-Year, Gender, and Industry.

## How to Use
1. **Clone the Repository**:
   ```sh
   git clone https://github.com/your-username/Wage_Analysis_PowerBI.git
   ```
2. **Open the Power BI file** (`wage_analysis.pbix`) in **Power BI Desktop**.
3. **Explore the Dashboard** by interacting with filters and visuals.
4. **Modify the Data Source** if using real data.
